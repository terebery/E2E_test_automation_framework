# Text Box — Test Requirements

## FR-05: Successful form submission displays output panel
**As a** user
**I want to** fill in the text box form and submit it
**So that** I can see my data reflected in the output section

### Acceptance criteria
- Form accepts full name, email, current address and permanent address
- On submit an output panel appears below the form
- Output panel displays correct full name
- Output panel displays correct email address
- Output panel displays correct current address
- Output panel displays correct permanent address

---

## FR-06: Output panel is not visible before submission
**As a** user
**I want to** see a clean form on page load
**So that** I am not confused by leftover data from previous sessions

### Acceptance criteria
- Output panel is not visible when page is first loaded
- Output panel appears only after clicking Submit
